# 中文地址确认与本地模拟退款修复记录

本次仅修改当前项目，参考项目保持只读。功能范围为中文地址提取、客户确认后的地址申请，以及工作人员明确执行全额本地模拟退款。

## 已实现行为

地址工具从服务端本轮客户消息提取信息，不信任模型生成的新地址内容。规则提取中国省市区、街道和明确邮编，支持完整结构化 JSON。只从已核验同一订单补充可靠联系人；明确要求修改联系人或电话时不会回填旧值。缺少字段、格式错误或地址歧义时要求客户补充完整地址，尚不创建审批申请。复杂或无法确定的输入不额外调用模型猜测信息。

候选地址保存在独立的 `address_change_draft` 表，通过 Widget 买家 JWT 绑定租户与会话。Widget 显示完整六字段并提供“确认地址并提交审批”按钮。客户确认后，服务端重新检查订单归属、订单版本、草稿有效期及最新草稿，创建结构化 `ReturnRequest`。草稿行锁和唯一键防止重复创建；重复确认返回原申请的实际状态。草稿有效期为 30 分钟。客户确认不执行订单修改；工作人员仍需分别批准和执行。

地址创建和执行共用 `AddressNormalizationService` 校验，执行器继续使用已审批内容。历史纯文本申请保持原样，旧批准状态不会套用于新申请，失败审计不删除。

退款只支持本地 `DEMO/LOCAL` 订单的首次全额退款，申请金额和币种必须等于已支付订单总额及币种。通过 JWT、`action:execute`、租户和动作策略校验的工作人员，明确点击“执行本地模拟退款”并确认后，接口才接受 `executionMode=LOCAL_SIMULATION`。审批按钮不执行退款，Agent 没有退款执行工具。

成功后同一事务登记 `order_status=refunded`、`payment_status=refunded`、`refunded_amount=total_amount`，更新申请状态并保存执行审计。成功审计保留唯一约束；申请和订单行锁防止同申请重复执行及不同申请重复登记同一订单。任一步失败全部回滚，已有机制另行记录失败审计。收货地址、物流及历史字段保持原值。

审计新增 `execution_mode` 和 `payment_refund_confirmed`。本地退款为 `LOCAL_SIMULATION`、`EXECUTED`、`false`，没有真实支付流水。后台订单列表、详情和订单工具通过关联成功执行记录显示模拟来源。`OrderTools` 现在传递最新支付状态、售后进度、模拟来源和实际支付确认信息，提示词要求查询真实记录，并明确不能将批准或模拟登记描述为资金到账。

工具审计中收货地址脱敏，地址相关 Agent 轨迹脱敏，关闭 SQL 标准输出，草稿、审批及客户会话业务数据保留原始输入，工具日志和轨迹不输出完整地址。

## 数据库迁移

新增 `sql/db_address_refund_execution.sql`，依赖此前已存在的 `commerce_action_record` 表。迁移只创建地址草稿表及增加审计字段，不回填或覆盖历史订单、审批或审计。本地数据库已执行，并验证重复执行成功。

## 验证结果

- `mvn clean compile -DskipTests`：通过。
- `mvn -pl omni-merchant-agent -am test`：通过；Agent 模块 309 项，无失败、错误或跳过。
- `mvn -pl omni-merchant-bootstrap -am test`：通过；Bootstrap 模块 65 项，无失败、错误或跳过，其中 `WidgetHumanExecutionMySqlTest` 31 项使用真实 MySQL。
- `npm run build`：通过，保留已有大包体积提示。
- 前端消息时序回归：1 项通过；该用例使用接口桩，不作为真实业务联调证据。
- 真实浏览器联调：使用 Edge、实际 DeepSeek、实际后端和 MySQL，验证 Widget 中文地址 → 完整字段展示 → 客户确认 → 待审批 → 批准 → 单独执行，以及 Widget 退款申请 → 批准但订单不变 → 明确本地模拟执行 → 订单列表显示模拟来源 → Widget 查询说明模拟且实际支付未确认。最终证据见 `docs/evidence/address-refund-2026-10-13.json`。

真实数据库测试只新建独立 `IT-LOCAL-*`、`#AR*` 演示订单。自动化 MySQL 用例清理自身创建的记录，浏览器联调订单和审计保留供检查。没有修改现有真实业务订单或历史审批。

最终后端测试实例使用端口 18080，Widget 与后台前端使用 `http://127.0.0.1:15173`。后台普通客服不能执行退款，主管或管理员还必须满足本租户动作策略。IDEA 中其他运行实例未停止或替换；其生效需要运行最新代码与新增迁移。
